# Versions

## 1.1.0 — 2026-08-12

Adds `exposure-audit`. 18 skills.

**Security**
- exposure-audit — a 20-point sweep of your own setup, run in the right order: scope the
  surface first, then score the checklist against it. Catches the three things published
  vulnerability lists miss — live keys inside cloud-synced folders, unrevoked keys from
  products that were shut down, and abandoned deployments still holding environment
  variables. Never prints a secret value, never calls a state-changing endpoint, and
  reports NOT RUN instead of guessing when a check does not complete.
